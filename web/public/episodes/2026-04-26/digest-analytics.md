# Databricks Weekly: Analytics & Data Science - Apr 19 - Apr 26, 2026

## The Big Ones

### 1. **OpenAI GPT-5.5 + Codex, now available and fully-governed in Databricks (and the partnership behind it!)**
**Source:** [Databricks Blog - OpenAI GPT-5.5 now available](https://www.databricks.com/blog/openai-gpt-55-now-available-databricks-fully-governed-through-unity-ai-gateway), [Databricks Blog - Databricks partners with OpenAI](https://www.databricks.com/blog/databricks-partners-openai-gpt-55)
**Why it matters:** This is a **massive announcement** for anyone building GenAI solutions on Databricks. The immediate availability of OpenAI's GPT-5.5 and Codex within Databricks, fully governed through Unity AI Gateway, means data scientists and ML engineers can now leverage one of the most powerful frontier models for complex agentic work directly in their secure, enterprise environment. This dramatically simplifies the integration of advanced LLMs into RAG systems, agents, and intelligent applications, removing significant hurdles around security, governance, and model deployment. This partnership underscores Databricks' commitment to providing seamless access to leading GenAI capabilities.

### 3. **How conversational analytics removes the BI bottleneck**
**Source:** [Databricks Blog](https://www.databricks.com/blog/how-conversational-analytics-removes-bi-bottleneck)
**Why it matters:** This is a key development for SQL Analytics and AI/BI practitioners. Conversational analytics, powered by LLMs, promises to democratize data access by allowing business users to ask questions in natural language and receive instant, insightful answers. For data analysts and data scientists, this means a shift from building static dashboards to creating intelligent, interactive systems that can significantly reduce the "BI bottleneck." Understanding how to design and implement these conversational interfaces within Databricks SQL will be crucial for empowering users and driving faster insights.

### 4. **Announcing the Public Preview of Lakeflow Designer**
**Source:** [Databricks Blog](https://www.databricks.com/blog/announcing-public-preview-lakeflow-designer)
**Why it matters:** (In Public Preview) While Lakeflow Designer is primarily a data engineering tool for building visual data pipelines, its public preview is important for data scientists and analysts. Clean, well-prepared data is the foundation of any successful analytics or machine learning project. Tools that simplify and accelerate the ETL/ELT process, like Lakeflow Designer, directly contribute to data quality and accessibility. By providing a low-code/no-code interface for data ingestion and transformation, it can empower data science teams to more efficiently prepare data for exploratory analysis, model training, and feature engineering, reducing dependencies on specialized data engineering resources.
